# Offline image payload

The final offline package adds these generated files to this directory:

- `dsv4-a100-r1-images.tar`: deduplicated Docker save archive containing the
  immutable base, R1 runtime, and R1 source-test images.
- `dsv4-a100-r1-images.tar.sha256`: payload checksum.
- `offline-images.env`: exact image IDs and payload identity used by the loader.

They are generated by `r1/scripts/package_offline_release.sh` after all images
have been built and verified with `r1/scripts/build_precompiled_images.sh`.
They are intentionally not committed to Git.
