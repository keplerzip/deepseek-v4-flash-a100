# 现场测试数据

本目录保存 2026-08-13 目标机测试的结构化摘录。数据来自操作者粘贴到部署会话中的
终端输出；目标机生成的原始 JSON、GPU CSV 和完整日志尚未复制回本项目。

证据等级：

- `A`：原始结果文件已归档并可重新解析；
- `B`：保留了带结果文件名或时间戳的逐字终端输出，但原始文件未归档；
- `C`：由日志容量或上下文比例推导，不是独立实测。

当前三个 CSV 都是 `B`。报告中的 256K 理论 KV 并发 `19.58x` 是用 512K、
`max_num_batched_tokens=4096` 启动日志中的 `9.79x` 线性折算，因此单独标为 `C`。

不要把 `decode_tps_mean` 与 aggregate throughput 混用：前者是成功请求各自 decode
速率的算术平均；后者是同一并发组总输出 token 除以整组 wall time，包含 TTFT。
